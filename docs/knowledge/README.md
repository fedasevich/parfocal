# Knowledge

Durable lessons that a later session must not rediscover the hard way. One file per topic, such as `viewer.md`, `formats.md`, `tiles.md`, `ml.md`, `auth.md` or `ci.md`. Create a topic file when its first lesson arrives and add it to the table below.

Each lesson is a short entry with a heading, what happens, why, what to do about it, and a link to the log entry, result or ADR it came from. Edit entries when they become outdated rather than adding contradicting ones.

The POC lessons already carried into the backlog (doc 24 memory leaks, doc 31 overlay budgets, reader correctness traps and others) are not copied here. Add them when they are confirmed in this codebase.
