# Result: short topic

- Date: YYYY-MM-DD
- Backlog: task ID
- Kind: spike, benchmark, baseline, ML evaluation, load test or user study
- Commit: short SHA of the code that was measured
- Environment: machine, OS, browser and version, GPU, network shaping
- Data: fixtures, slides, datasets or participants (no PHI)

## Question

What this run was meant to answer, and the budget or POC number it is compared against.

## Method

Exact steps, commands and settings, so someone else can repeat the run.

## Results

Raw numbers in tables. Facts only.

## Interpretation

What the numbers mean, with assumptions labelled as such.

## Follow-ups

ADRs written, backlog tasks added or changed, and open questions marked `TODO`.
