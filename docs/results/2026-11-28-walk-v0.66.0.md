## Question

Does the deployed clause of each of the four tasks hold on app.parfocal.eu at release v0.66.0?

## Method

Throwaway Playwright scripts in the agent scratchpad ran against `https://app.parfocal.eu` with the storage state saved to `~/.config/parfocal/walk1128-session.json`, one headless page at a time. They log what they measure and each task is judged from those numbers. No screenshot was opened. The account's active workspace was `cvut-study` at the start and was set to `cvut-biomedical` with `PUT /api/me/workspace`. It was moved to `cvut-ml` and `cvut-imaging` for a few seconds each to read the estimates route and then set back.

- PROTO-178: the bar was hovered open, then every visible button, the scale bar and the readout were measured against the bar and against each other, as `apps/web/e2e/disagreement-big-view.spec.ts` does. No decide button was pressed.
- PROTO-206 and PROTO-182: the slide was opened from "Sample · sentinel nodes", zoomed by wheel to a known nucleus (image point 21418, 15403 on CMU-1.tiff at zoom 2^1.04, and 43476, 24152 on test_065 at zoom 2^1.29), Smart select armed from the rail, then: click cell A, plain click inside A's outline, click 70 px or more to the right for cell B, plain click inside kept A, Enter. The typer's times were read from the `outlines.typed` audit events.
- PROTO-211: the estimates route was read for every slide, then `/projects/{id}/run-model` was opened with test_065 picked and the Objects tab of the annotate viewer was opened on test_065 and CMU-1.ndpi. Neither Run nor Find nuclei was pressed.

## GPU time and cost

Two typer calls ran (8.04 and 5.864 GPU seconds by the audit events) and one Best embeddings call (22.9 s wall). `modal billing report --for today` showed the GPU app at $0.55603214 at 13:27 UTC before the walk and $0.60227894 at 13:43 UTC after it, and the api app at $0.07594920 and $0.08306116. So the walk cost at most $0.0462 of GPU and $0.0071 of api time. Other agents used the same apps in that hour, and the report may lag the last minutes, so the GPU figure is an estimate.
