## Why the zip slides do not open

- Both slides fail the same way, in the browser, before any pixel is asked for.
- GET /api/slides/{id}/tile-access answers 200 with format "mirax" (or "dicom") and original "original.zip".
- GET /tiles/{id}/levels.json answers 200. The table comes from OpenSlide for MIRAX and from wsidicom for DICOM. Its levels have sizes but no page and no directory offset, and the MIRAX tile sizes are null, so there is nothing a browser reader could follow.
- The browser then stops. signedOpenRequest in packages/viewer-engine/src/access/signed-slide.ts:300 builds the request, and registry.open in packages/viewer-engine/src/pixel-source/registry.ts:35 throws UnsupportedFormatError, because createDefaultPixelSourceRegistry at registry.ts:82 has openers for the TIFF family, NDPI, BIF and Zarr only. apps/web/src/viewer/open-failure.ts:31 turns that into the message on screen.
- Two more things would stop it even with a reader. A direct range read of /tiles/{id}/original.zip with a valid token answered 403. apps/api/src/parfocal_api/tile_access.py:158 closes the whole file when a slide has no restricted ranges file, and apps/edge/src/tiles.ts:327 then refuses every range. GET /tiles/{id}/tile-index.json answers 404, so no tile index was written at ingest.
- Nothing converts these slides either. The seed in apps/api/src/parfocal_api/showcase.py:178 points the slide at the fixture zip itself, and no converted pyramid exists next to it.
- The smoke already knows: apps/web/smoke/seeded-formats.spec.ts:76 skips the MIRAX and DICOM tests. PROTO-100 (a slide that came in a zip reads as its own format) only renames these slides and will not make them open.

## Do the viewer tabs and tools fit the task

- Guided review has no rail and three tabs, which fits. The opinion questions come at the end, which fits.
- Review has Select, Pan, Measure, Comment, Smart select and Compare with Objects, Display, Comments and Opinion, which fits. Smart select is odd in a mode where the reviewer does not draw.
- Annotate has the full rail. Its Objects tab holds Find nuclei, counts and measurements, while the drawn shapes, groups and result sets sit under Display. A person looking for what they drew opens the wrong tab first.
- Cells mode read only drops Comment and the Comments and Opinion tabs, which fits.
- A slide that failed to open keeps every tool and tab, which does not fit.
